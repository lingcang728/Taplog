# 项目文档（Group 17）

这里放的是课程设计项目的计划和文档，大家都在这里改。改完以后提交并推送，别人 `git pull` 就能看到最新版本。

| 文件 | 用途 |
|---|---|
| [项目总计划.md](项目总计划.md) | 整个项目先做什么、后做什么，以及每一步具体怎么做 |
| [任务表.md](任务表.md) | 待办清单，做完一项就把 `- [ ]` 改成 `- [x]` |
| [Proposal.md](Proposal.md) | 项目提案的英文草稿，附写作说明 |
| [最终报告.md](最终报告.md) | 最终报告的工作稿，按课程模板排好章节。每完成一项任务就往里写一点 |
| [materials/素材登记.md](materials/素材登记.md) | 讲座素材的登记表 |
| [materials/字幕扫描结果.md](materials/字幕扫描结果.md) | 字幕扫描脚本的输出 |
| `figures/` | 报告要用的图 |
| `../../tools/scan_caveats.py` | 扫描讲座字幕，找出“隔很久才补充或改口”的候选句子 |

## 约定

- **视频和字幕不进仓库**：体积大，也有版权问题，在组内网盘共享。
- **提示块**：标着 TIP 的灰色提示块是写作提示。报告和 Proposal 交稿前全部删掉。
- **题目定位**：所有文档都只写“讲座 / 演讲（talk）”，不写课堂、上课、复习这类说法。
- **字幕扫描脚本**的用法：

```bash
python3 tools/scan_caveats.py <字幕文件夹>/*.srt -o docs/project/materials/字幕扫描结果.md
```
