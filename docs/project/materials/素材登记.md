## 三、本地文件与复用说明

讲座视频、时间戳字幕和逐字稿不放进本仓库（体积大，也有版权问题），在组内网盘共享。
后续如果要补充下载其他 B 站讲座，可以用黄奕滔本地的下载脚本：
```bash

```
